# Mi Portafolio

Portafolio web personal desarrollado con Vue y Vite para presentar mi perfil, habilidades y proyectos academicos y de desarrollo de software.

## Descripcion

Este sitio fue creado como una carta de presentacion digital. Reune una breve introduccion sobre mi perfil, una seccion sobre mis habilidades y una galeria de proyectos con enlaces a repositorios y videos demostrativos.

## Tecnologias utilizadas

- Vue 3
- Vite
- JavaScript
- CSS3
- HTML5

## Secciones del portafolio

- `Inicio`: presentacion principal del portafolio.
- `Sobre mi`: resumen de perfil, habilidades blandas y tecnologias.
- `Proyectos`: muestra algunos de mis trabajos mas representativos.
- `Contacto`: enlaces a correo, GitHub y LinkedIn.

## Instalacion y uso

1. Clona el repositorio:

```bash
git clone https://github.com/Sofi-06/portafolio
```

2. Entra a la carpeta del proyecto:

```bash
cd mi-portafolio
```

3. Instala las dependencias:

```bash
npm install
```

4. Inicia el entorno de desarrollo:

```bash
npm run dev
```

## Scripts disponibles

```bash
npm run dev
npm run build
npm run preview
```
